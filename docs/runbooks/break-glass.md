# Break Glass Runbook

## What is Break Glass?
Emergency access to systems when normal access is unavailable.

## When to Use
- Primary auth is down
- Emergency incident response
- Urgent security fix needed

## How to Request
1. Open break glass request
2. State reason and duration
3. Get approval (or use emergency fallback)
4. Action taken logged
5. Review within 24 hours

## Actions
- List active break glass sessions
- Revoke immediately if suspicious
- Mandatory post-action review
